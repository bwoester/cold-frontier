# HoloCard Component

A reusable card component that implements the holographic UI style seen in the game navigation. This component provides a consistent look and feel for cards across the application with customizable properties.

## Features

- Holographic semi-transparent background with overlay effects
- Customizable glow intensity
- Corner accents that can be selectively shown
- Custom border styling options
- Pulse animation effects
- Customizable colors
- Title section with sci-fi bracket styling
